OpenSayo v1.15 — Windows Application

To launch with Python 3.12 installed, double-click RUN_OPENSAYO.bat.
To build the Windows executable, double-click BUILD_WINDOWS_EXE.bat.
After a successful build launch dist\OpenSayo\OpenSayo.exe from its complete folder.

For IT approval details and test instructions, see the IT_Review folder in the parent directory.
The staged test batches appear interactively in chat; the master IT plan is in IT_Review. Do not test device writes until the hardware validation stage.
Your personal configuration definitions must remain separate from this package.

Readback note: supported device macros restore their text and navigation actions to Form View and remain available in Macro Viewer. Check both previews after importing. Unrepresentable scripts are rejected without changing your current form.
